# Security policy

Tripwire is a tripwire, not a sandbox: it flags and blocks what the hooks can see. Known gaps are listed under "Honest limits" in the README.

## Reporting a bypass or vulnerability

Please report privately through GitHub's [private vulnerability reporting](https://github.com/percius47/agent-tripwire/security/advisories/new) rather than opening a public issue. Include the agent (Cursor or Claude Code) and its version, your OS, and the steps to reproduce.

## Supported versions

Only the latest published version on npm gets fixes.
